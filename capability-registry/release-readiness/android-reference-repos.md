# Android Reference Repositories

These are official Android/Google reference implementations, not requirements.

## android/nowinandroid
Production-oriented sample that demonstrates current Android architecture and engineering practices, including modularization, tests, CI/build and performance-related assets. Use it to compare implementation patterns, never as a blind template.

## android/architecture-samples
Reference architectures and testable application structure. Use for architecture/testing examples relevant to the target stack.

## android/testing-samples
A corpus of official Android testing examples. Prefer the exact sample matching the test problem rather than inventing a pattern.

## android/architecture-templates
Official starter/template patterns for modern Android projects. Use when bootstrapping a compatible project or comparing project setup.

## Provenance rule
Before adapting code, inspect the current upstream file and its license, record repository/path/revision, and adapt only the relevant pattern.
