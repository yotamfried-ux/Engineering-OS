# Trivy

**Source:** Aqua Security `aquasecurity/trivy` and official documentation.

## Use
Scan applicable repositories/filesystems/images for known vulnerabilities, secrets and infrastructure-as-code/configuration problems. Explicitly configure the scanner modes needed by the project.

## Evidence
Record Trivy version, target identity/digest, enabled scanners, severity policy, databases used, findings and suppressions.

Do not report an unenabled scanner as covered.
