# OSV-Scanner

**Source:** Google `google/osv-scanner` and official OSV-Scanner documentation.

## Use
Software composition analysis: identify packages from supported manifests/lockfiles/source or container images and match them against vulnerability data.

## Evidence
Record scanner version, vulnerability DB/advisory freshness where available, files/images scanned, ignored findings with justification, and unresolved vulnerabilities.

A clean SCA run says nothing about first-party logic vulnerabilities.
