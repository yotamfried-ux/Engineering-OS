# OpenSSF Scorecard

**Source:** OpenSSF `ossf/scorecard`.

## Use
Assess repository and software-supply-chain security practices using automated checks. Useful as repository-posture evidence and CI hygiene guidance.

## Does not prove
Application runtime security or absence of exploitable vulnerabilities.

## Evidence
Record Scorecard version, repository/revision, checks executed and individual findings. Do not convert the aggregate score into an application-security verdict.
