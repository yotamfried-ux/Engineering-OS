# OWASP ZAP

**Source:** OWASP ZAP project; repository `zaproxy/zaproxy`.

## Use
Dynamic application security testing of authorized running Web/API targets. Suitable for automated baseline/API/full scans and interactive investigation.

## Proves
Findings observed by the configured ZAP scan against the exact reachable target.

## Does not prove
Absence of business-logic, authorization, source-code, dependency, secret or infrastructure vulnerabilities.

## Qualification evidence
Record ZAP version, target/deployment, authentication context, scan policy, included/excluded paths, alerts by risk/confidence and raw report. Map applicable findings/tests back to ASVS/WSTG where possible.
