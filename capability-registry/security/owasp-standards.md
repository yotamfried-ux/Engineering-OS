# OWASP Security Standards Corpus

## Web/API
- **ASVS 5.0.0** — requirements/control baseline.
- **WSTG 4.2 stable** — executable/manual testing scenarios. Pin versioned scenario identifiers.

## Mobile
- **MASVS** — mobile application security requirements.
- **MASTG** — mobile testing techniques and test cases.
- **MASWE** — weakness taxonomy.

## Rule
Use standards to decide what is applicable, then map executable tools/manual tests to those controls. Tool coverage is never assumed to equal standard coverage. Store PASS/FAIL/PARTIAL/BLOCKED/NOT TESTED/NOT APPLICABLE per applicable requirement/scenario with evidence.
