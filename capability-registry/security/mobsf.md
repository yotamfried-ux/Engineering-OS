# Mobile Security Framework (MobSF)

**Source:** `MobSF/Mobile-Security-Framework-MobSF`.

## Use
Android/iOS mobile security analysis. Use static analysis for packages/source and dynamic analysis where the host/device prerequisites are available. It also exposes automation/CI APIs.

## Proves
Only the checks actually executed on the supplied artifact/runtime.

## Does not prove
Complete MASVS/MASTG coverage, business-logic correctness or backend/API authorization.

## Qualification evidence
Record MobSF version, APK/AAB/IPA/source identity, hash, static/dynamic mode, platform/device, findings and report. Map findings and missing manual tests to MASVS/MASTG.
