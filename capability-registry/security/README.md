# Security & Release-Readiness Capabilities

Use these assets to select authoritative standards, executable security tools and reference implementations. They complement `patterns/security/` and the project qualification matrix.

## Included executable capabilities
- OWASP ZAP — Web/API DAST.
- MobSF — Android/iOS static and dynamic security analysis.
- OSV-Scanner — open-source dependency/SCA scanning.
- Trivy — vulnerability, container, IaC/misconfiguration and secret scanning.
- Gitleaks — focused secret detection in working trees and Git history.
- OpenSSF Scorecard — repository/supply-chain security posture.

## Included authoritative standards/corpora
- OWASP ASVS — Web/application security requirements.
- OWASP WSTG — Web security testing scenarios.
- OWASP MASVS + MASTG + MASWE — mobile requirements, tests and weakness taxonomy.

## Included Android reference implementations
- android/nowinandroid
- android/architecture-samples
- android/testing-samples
- android/architecture-templates

## Release readiness
Google Play release/testing requirements and Play pre-launch reports are authoritative external gates. They are documented as vendor workflow rather than represented as a third-party repo.

Never infer overall security/readiness from one tool.
