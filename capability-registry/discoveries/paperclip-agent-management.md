# Paperclip AI — multi-agent organization management

Canonical source: https://github.com/paperclipai/paperclip
Official docs: https://github.com/paperclipai/paperclip-docs
Status: CANDIDATE / NOT INSTALLED / NOT QUALIFIED.

Paperclip provides an orchestration control plane for multiple agent runtimes, with tasks, goals, hierarchies, approval gates, budgets, heartbeats, skills, run histories and scoped connections. Compare against existing Engineering-OS orchestrator, agent roles, budgets and self-improvement gates before adoption; do not install an overlapping control plane without demonstrating added value.

Security/qualification: audit adapter subprocess execution, scoped credentials, org isolation, task atomicity, budget enforcement, approval semantics, database migrations and network exposure. Run representative workflows in isolation and compare measured reliability, cost and operator time. Never infer that a polished UI proves autonomy or production safety.
