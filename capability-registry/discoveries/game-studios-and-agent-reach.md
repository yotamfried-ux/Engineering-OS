# Game studio agents and cross-platform research access — source-backed candidates

Status: **CATALOG ONLY / NOT INSTALLED / NOT QUALIFIED** (2026-11-14). Social-media posts were discovery hints only, not knowledge sources.

## Claude Code Game Studios
Canonical: https://github.com/Donchitos/Claude-Code-Game-Studios
Upstream README describes a game-development coordination framework with specialist agents and workflows for game design, programming, QA and production. The repository describes browser-game prototyping and engine-specific workflows. Useful for a game project where specialized roles improve coordination, **not** a reason to replace an existing engineering orchestrator. Inspect actual agent prompts, dependency footprint, supported engines, license, test framework, cost and overlap with Engineering-OS before adoption. Do not assume an advertised agent count measures effectiveness.

## Agent Reach
Canonical: https://github.com/Panniantong/Agent-Reach
Official English documentation: https://github.com/Panniantong/Agent-Reach/blob/main/docs/README_en.md
Upstream describes a CLI-based selection/health-check layer over multiple content retrieval backends, including web, YouTube, Reddit, X, GitHub and social sites. Instagram access described by the project relies on a local desktop browser session/OpenCLI, **not** universal unauthenticated reel/video playback. Some sources require login/cookies, optional external services or proxies. Respect terms, privacy, authentication and rate limits. Audit installation scripts and cookie handling before any connection. Compare existing browser/video-analysis connectors before adoption.
