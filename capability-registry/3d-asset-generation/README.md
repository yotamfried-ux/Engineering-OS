# 3D Asset Generation

Purpose: route tasks that create, revise, inspect, or operationalize 3D assets without mixing them into generic image-generation, testing, or agent-orchestration capability buckets.

## Capabilities

- [Kiln](./kiln.md) — AI-assisted 3D asset authoring, revision, and inspection workflow.

## Routing guidance

Use this area when the task's primary artifact is a 3D asset, scene, mesh, material, texture set, or 3D-ready package.

Do not route ordinary 2D image generation here. Do not treat presence in this library as proof that the target host has the tool installed or connected; verify the target runtime before depending on it.
