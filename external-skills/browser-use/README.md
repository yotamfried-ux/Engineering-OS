# Browser Use

**Upstream:** `browser-use/browser-use`

AI browser automation for navigation, interaction, extraction, research and workflow automation. Upstream also exposes MCP/browser-control capabilities.

Use for exploratory/high-level browser automation when deterministic Playwright tests are not the better fit. For qualification, keep Playwright as the preferred deterministic regression evidence where possible. Restrict domains/credentials and verify on harmless authorized targets.
