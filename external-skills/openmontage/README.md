# OpenMontage

**Canonical upstream:** `calesthio/OpenMontage`

Open-source agent-first video production system. It provides production pipelines, tools, agent skills, quality/review gates, checkpointing and rendering workflows for research, scripting, assets, editing and composition.

Use when an agent must create or transform complete videos rather than only analyze them. Particularly relevant to video-editing projects and reference-video-driven production. Current upstream requires Python/FFmpeg/Node and a coding agent; provider/API requirements depend on the selected pipeline.

Qualification: start with upstream contract tests, then run a small representative production and verify the rendered media, artifact schemas, provenance/cost metadata and review gates. Do not treat a successful render alone as proof of editorial quality.
