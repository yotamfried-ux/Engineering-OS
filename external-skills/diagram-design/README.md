# Diagram Design

**Upstream:** `cathrynlavery/diagram-design`

Agent skill for editorial/system diagrams using self-contained HTML + SVG, including architecture, deployment, dependency, database-schema, UML, journey and other layout grammars.

Use when a project needs readable technical diagrams or to redraw Mermaid/draw.io/Excalidraw material. Verify rendered output and semantic accuracy; visual polish does not validate the underlying architecture.
