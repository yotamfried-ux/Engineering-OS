# Agency Agents

**Canonical upstream:** `msitarzewski/agency-agents`

Collection of specialized AI-agent definitions/personas/workflows spanning engineering, design, marketing, product and other roles. Upstream also provides installation paths for multiple coding-agent hosts.

## Use when
Use as a source of specialized role instructions when a task benefits from a focused expert workflow rather than a generic coding agent.

## Qualification
Treat individual agents as prompts/workflow assets, not automatically trusted experts. Inspect the exact agent definition before use, check for external commands/tools/permissions, test it on a bounded task with objective acceptance criteria, and retain only agents that add measurable value over the base agent.

**Status:** REFERENCE / SELECTIVE IMPORT — do not bulk-activate every agent.
