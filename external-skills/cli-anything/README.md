# CLI-Anything

**Canonical upstream:** `HKUDS/CLI-Anything`

Framework/methodology for turning software with a codebase into an agent-controllable CLI harness. The upstream pipeline covers analysis, CLI design/implementation, test planning, tests, documentation and publishing, with generated harness docs and tests.

Use when an agent needs deterministic structured control over software that otherwise exposes mainly a GUI. Follow current upstream install/HARNESS documentation. Verify generated CLI help, structured output and representative end-to-end operations; do not assume one generation pass covers all application capabilities.
