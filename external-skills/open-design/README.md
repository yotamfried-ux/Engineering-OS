# OpenDesign

**Canonical upstream:** `nexu-io/open-design`

Local-first open design workflow/platform that lets coding agents create prototypes, dashboards/artifacts, decks, images, video/motion graphics and reusable design-system outputs through composable skills/plugins.

Use when an agent needs broader product/design production than the focused UI/UX guidance already cataloged. Treat it as a substantial optional capability, not an automatic dependency. Verify current host compatibility, sandbox/export behavior, selected plugins/skills and produced artifacts before adoption.
