# Codebase Memory MCP

**Canonical upstream:** `DeusData/codebase-memory-mcp`

Persistent structural code-intelligence MCP. It indexes repositories into a knowledge graph and exposes structural queries to MCP-compatible coding agents. Upstream documents tree-sitter based parsing, persistent local storage, graph queries, optional UI, stdio/streamable-HTTP transports and agent setup.

## Use when
Use for large or unfamiliar repositories where repeated code discovery, call-chain tracing and cross-session structural understanding consume substantial context/tokens.

## Overlap
Compare with Graphify and Graft before installing. Prefer the smallest capability that solves the task; do not run multiple codebase indexes by default.

## Qualification
Install only from the canonical upstream/release, inspect installer changes before execution, index a disposable/test repository, confirm MCP initialize/tools listing, query known symbols/call paths, mutate the fixture and verify re-index/update behavior. Record host, version and transport.

**Status:** CANDIDATE / HOST-DEPENDENT until qualified on the target agent host.
