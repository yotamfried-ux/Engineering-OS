# Hermes Agent

**Canonical upstream:** `NousResearch/hermes-agent`

General-purpose CLI/TUI AI agent with selectable providers/models, toolsets, skills, session continuation and terminal-centric workflows.

## Use when
Use as a reference or alternative agent runtime when a task benefits from a terminal-native personal agent and its skill/tool ecosystem. Do not automatically replace the user's existing Codex/Claude/ChatGPT workflow with Hermes.

## Qualification
Use the canonical upstream setup. Verify CLI version, a harmless single-query run, explicit toolset loading, one bounded skill, session resume and permission behavior. Never enable approval-bypass modes by default.

**Status:** REFERENCE / OPTIONAL HOST-DEPENDENT RUNTIME.
