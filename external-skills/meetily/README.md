# Meetily

**Canonical upstream:** `Zackriya-Solutions/meetily`

Privacy-first open-source meeting assistant for local/self-hosted transcription and meeting summaries. Upstream supports local transcription and multiple summarization providers, including a fully local Ollama path.

## Use when
Use when a project needs private meeting capture, transcription, notes or summaries without making a cloud meeting bot the default.

## Qualification
Verify install/build on the target OS, microphone/audio capture, local transcription, transcript persistence, one summary path, export, and network behavior of the selected AI provider. Record version, models/provider and whether processing remained local.

**Status:** READY AS KNOWLEDGE / HOST-DEPENDENT.
