# Instagram Agent Skill — creator content drafting suite

**Canonical upstream:** https://github.com/Jakeschincariol/instagram-agent-skill
**Status:** CANDIDATE / NOT INSTALLED / NOT QUALIFIED.
**License:** upstream README states MIT; check LICENSE and dependencies before reuse.

Upstream describes 13 Claude skills for Reel scripts, hook scoring, captions, carousel/story drafts, profile review, weekly plans, engagement reply drafts, repurposing and post-mortem. Local Python helpers score and lint content. This is **content planning and drafting**, not a connected Instagram account manager. The upstream explicitly states that publishing requires the human: “These skills write. You post.”

Use when producing a reviewable, brand-consistent social content plan. Compare against `docs/product-experience/analytics-experimentation-growth.md` and `docs/product-experience/video-hooks-and-retention-research.md`. Do not infer that a numerical hook score proves conversion lift or that viral research establishes causality.

No automated following, unsolicited DMs, engagement spam, browser scraping or publication without explicit user approval and a legitimate supported platform integration. Check the code of all 13 skills, scripts, local file I/O, licenses, personal-data handling, API terms and costs before any installation or promotion.
