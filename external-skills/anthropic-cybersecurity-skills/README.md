# Anthropic Cybersecurity Skills (community repository)

**Upstream:** `mukul975/Anthropic-Cybersecurity-Skills`

Large community-maintained cybersecurity Agent Skills corpus with mappings to frameworks such as MITRE ATT&CK and NIST CSF and skills spanning defensive and authorized offensive workflows.

Despite the repository name, treat this as a third-party/community asset, not an official Anthropic security standard. Route authoritative application-security qualification through OWASP/NIST and verified tools first. Select only relevant skills, inspect their scripts/references before execution, and require explicit authorization for offensive actions.
