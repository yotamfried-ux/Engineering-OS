# Canonical source register

This register identifies upstream authorities, not copied or frozen policy text. Check the linked current version before shipping.

| Area | Tier A authority | Refresh |
|---|---|---|
| Security | https://owasp.org/www-project-application-security-verification-standard/ | At new ASVS version |
| Mobile security | https://mas.owasp.org/ | At qualification |
| Secure SDLC | https://csrc.nist.gov/Projects/ssdf | At new revision |
| Reliability | https://sre.google/books/ | At architectural changes |
| Web performance | https://web.dev/learn/performance | At optimization |
| Accessibility | https://www.w3.org/TR/WCAG22/ | At design and launch |
| Supabase RLS | https://supabase.com/docs/guides/database/postgres/row-level-security | At schema/policy changes |
| Stripe webhooks | https://docs.stripe.com/webhooks/signature | At payments changes |
| Apple review/privacy | https://developer.apple.com/app-store/review/guidelines/ | Every submission |
| Google Play policy | https://support.google.com/googleplay/android-developer/answer/10144311 | Every submission |
| Israel privacy | https://www.gov.il/he/departments/the_privacy_protection_authority | Each legal review |
| Israel consumer protection | https://www.gov.il/he/departments/consumer_protection_and_fair_trade_authority | Each legal review |
| US copyright safe harbor | https://www.copyright.gov/dmca-directory/ | If applicable |
| GDPR | https://eur-lex.europa.eu/eli/reg/2016/679/oj | If applicable |

Source quality rule: official legal texts and regulators outrank commentary; vendor policies outrank influencer videos. Avoid static fine amounts, unsupported mandatory claims and jurisdiction-free legal templates.
