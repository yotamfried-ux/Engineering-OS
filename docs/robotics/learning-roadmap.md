# Robotics learning foundations — source-based route

The available source identifies a 30-day robotics learning theme but no reliable detailed syllabus. Do not attribute a particular curriculum to it.

Primary references: https://docs.ros.org/en/rolling/ ; https://mujoco.readthedocs.io/en/stable/ ; https://docs.arduino.cc/ ; https://huggingface.co/docs/lerobot/index

Progress from coordinate frames and kinematics to sensors/actuators, control, robot middleware, simulation, perception, and imitation/reinforcement learning. For each exercise require reproducible environment, safety limits, measurement and test results. Keep simulation and real hardware safety gates distinct. No installation or physical actuation.
