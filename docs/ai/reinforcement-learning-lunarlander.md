# Reinforcement learning with LunarLander

Primary sources: https://gymnasium.farama.org/environments/box2d/lunar_lander/ ; https://stable-baselines3.readthedocs.io/en/master/guide/quickstart.html

LunarLander is a benchmark environment for learning control policies from observations, actions and rewards. Explore reward shaping and policy optimization in a reproducible local experiment. Pin Gymnasium/Box2D and agent library versions; log seeds, evaluation episodes, reward curves, failure modes and compute. Compare shaped vs baseline reward and test held-out seeds. Avoid claiming a day-long tutorial proves general autonomous robotics capabilities. Catalog-only; no environment installed.
