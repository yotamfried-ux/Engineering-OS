# NVIDIA Kumo — structured-data foundation model

Official docs: https://docs.nvidia.com/sdgm/structured-data-models/overview ; https://docs.nvidia.com/sdgm/faq/kumo-foundation-models/which-foundation-model-should-i-choose

Kumo Relational predicts outcomes using related tables and schema relationships without training a separate task-specific model. It still requires labeled context examples, appropriate target specification and representative validation data. Compare against supervised baselines on time-split held-out data; inspect leakage, class balance, calibration, latency, deployment cost, licensing and privacy. “No training” does not mean “no data preparation,” “zero-shot guaranteed accuracy,” or replacement of traditional ML. Catalog reference only; no model downloaded.
