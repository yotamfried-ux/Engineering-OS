# OpenAI — WebMCP Challenge / WebMCP

**Official source:** OpenAI, “The WebMCP Challenge” (2026).

WebMCP is described by OpenAI as an experimental open web standard that lets websites expose structured tools directly to agents instead of requiring agents to infer every action from the visual UI.

## Why this belongs in Engineering-OS
When building a web application expected to work with agents, evaluate whether an explicit WebMCP tool surface can make important actions more deterministic, efficient and reliable than UI-only automation.

## Engineering rule
Do not invent a WebMCP implementation from social-media summaries. Before implementation, read the current OpenAI/Chromium specification/examples, confirm current browser/ChatGPT support and test the exact tools exposed by the site.

**Status:** OFFICIAL CONCEPT / EXPERIMENTAL STANDARD — re-check current support before implementation.
