# PCB design learning — canonical tooling and verification

Official tool documentation: https://docs.kicad.org/ ; https://www.kicad.org/help/documentation/

For an unidentified circuit-design demo, do not guess the product. KiCad provides a verified open-source reference workflow: schematic capture, electrical-rule checks, footprint assignment, PCB layout, design-rule checks, fabrication outputs and assembly review. Check current/thermal limits, component availability, creepage/clearance and manufacturing constraints. Mains/high-energy designs require competent electrical safety review.
