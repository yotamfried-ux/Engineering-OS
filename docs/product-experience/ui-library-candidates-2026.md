# UI component and motion library candidates

Status: discovery and official-source verification, **no dependency added** (2026-11-14). Use only where existing design-system components are insufficient. Check each component's license, accessibility, keyboard behavior, RTL, reduced-motion, bundle cost, maintenance and Next.js compatibility before copying/installing.

| Candidate | Canonical primary source | Assessment |
| --- | --- | --- |
| Vengeance UI | https://www.vengenceui.com/ | Official site describes animated React interactions, hover effects and registry-installable components; verify individual packages and licenses before use |
| Animate UI | https://animate-ui.com/docs | Official docs describe Motion-powered drop-in animated primitives for Radix UI, Base UI and React Aria; supports reduced motion and preserves existing shadcn structure |
| Uiverse | https://uiverse.io/ | Community-contributed CSS/Tailwind UI examples; inspect **each author's** license, code and accessibility independently |
| Forge UI | **canonical upstream not independently verified** | Do not install or claim specific features until project identity and official docs are confirmed |
| UI Lora | **canonical upstream not independently verified** | Do not install or claim cross-platform compatibility until official project identity is confirmed |

Prefer existing `docs/product-experience/premium-motion-and-design-systems.md` for design guidance. The candidate list is for task-specific discovery, not a recommendation to combine five UI libraries.
