# Awesome LLM Apps

**Canonical upstream:** `Shubhamsaboo/awesome-llm-apps`

Collection of runnable/open-source AI agent, Agent Skill and RAG application examples with source code and tutorials.

Use as an implementation-pattern and example source when building agent/RAG applications. Copy concepts selectively, not entire architectures by default. Before reuse inspect dependencies, credentials, model assumptions, tests, security boundaries and license; rerun the example on the current dependency versions.
