# Awesome MCP Servers

**Canonical upstream:** `punkpeye/awesome-mcp-servers`

Large curated directory of Model Context Protocol servers.

Use as a discovery source when Engineering-OS lacks a required capability. A listing is never qualification. For every candidate, locate the canonical upstream and verify ownership, maintenance, license, installation, transport/auth, permissions, secrets, destructive tools, tool schemas and a harmless smoke test before adding it to the capability registry.
