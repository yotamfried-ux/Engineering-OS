# Public APIs

**Canonical upstream:** `public-apis/public-apis`

Community-curated catalog of public/free APIs across many categories.

## Use when
Use as a discovery source when a project needs an external API and no preferred provider has already been selected.

## Qualification rule
A catalog entry is not proof that an API is still free, available, secure, stable, or suitable. Before integration, follow the candidate to its official provider documentation and verify authentication, pricing/quotas, CORS, terms, data handling, SLA/status, API version and a harmless live request.

**Status:** DISCOVERY SOURCE — not a runtime capability by itself.
