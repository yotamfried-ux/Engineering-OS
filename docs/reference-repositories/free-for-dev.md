# free-for-dev

**Canonical upstream:** `ripienaar/free-for-dev`

Curated directory of developer services with free tiers.

Use as a discovery source when selecting hosting, databases, monitoring, CI, APIs and other development services. Never treat a catalog entry as proof that a current free tier still exists or fits a project: verify pricing, limits, region, retention, data policy and terms on the provider's current official documentation before recommending or integrating it.
