# The Well

**Canonical upstream:** `PolymathicAI/the_well`

Large-scale collection and Python tooling for machine-learning datasets built from numerical simulations of spatiotemporal physical systems. Upstream describes 15 TB across 16 datasets and provides benchmark/data-loading tooling.

## Use when
Use for scientific-ML/physics-model research, simulation-learning benchmarks and examples of handling large structured scientific datasets.

## Qualification rule
Do not download the full corpus by default. Select only the required dataset/split, record dataset/version, storage cost and known dataset caveats. Treat benchmark baselines as baselines, not state of the art.

**Status:** REFERENCE + DATASET SOURCE.
