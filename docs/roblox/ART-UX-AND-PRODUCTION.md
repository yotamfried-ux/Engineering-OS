# Roblox art, UI/UX and content pipeline

Official starting points: [Creator Hub](https://create.roblox.com/docs), [Studio](https://create.roblox.com/docs/studio), [Game design](https://create.roblox.com/docs/production/game-design).

| Tool | Purpose | MCP status |
|---|---|---|
| [Roblox Studio](https://create.roblox.com/docs/studio) | world, terrain, animation, effects, playtesting | **official built-in MCP** |
| [Blender](https://www.blender.org/) | 3D modeling, UV, rigging, animations | community MCP integrations exist; review each separately |
| [Figma](https://www.figma.com/) | UI flows, HUD, inventory, responsive layouts | official Figma MCP offering; verify access and scope |
| [React Luau](https://github.com/Roblox/react-luau) | declarative Roblox UI | library, not MCP |

Production topics: readable silhouettes and visual hierarchy, mobile-first touch targets, controller and desktop input, accessible color and text, reduced motion when possible, localization, onboarding clarity, lighting, VFX, audio, rigging, texture/mesh budgets, streaming and frame-time profiling.

For design quality also consult existing `docs/product-experience/` and `3d-asset-generation/`. Check rights and licensing of imported models, textures, sounds and AI-generated assets; do not import unknown Creator Store scripts blindly.
