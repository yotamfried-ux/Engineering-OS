# OpenViking

**Canonical upstream:** `volcengine/OpenViking`

Open-source context database for AI agents that unifies memory, knowledge/resources and skills through a virtual-filesystem/context model with hierarchical/on-demand retrieval.

Use as a candidate context/memory substrate when a project needs structured long-running agent context. Do not assume upstream retrieval/token claims apply to our workloads; qualify retrieval quality, freshness, deletion/update behavior, security, storage/privacy and token cost on representative project data before adoption.
