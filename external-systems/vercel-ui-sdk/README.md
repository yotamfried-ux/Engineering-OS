# Vercel UI SDK

Status: REFERENCE ONLY / source verified; not installed or runtime-qualified.

https://github.com/vercel-labs/ui

## Use and verification
Beta behavior library for accessible keyboard navigation, focus, selection, dismissal and drag/drop. React 19+ adapter: npm install @ui-sdk/react @ui-sdk/core. Other adapters available. Agent skill: npx skills@latest add vercel-labs/ui --skill ui-sdk. Docs: https://ui-sdk.dev/docs/react . Test keyboard, screen reader, RTL and focus recovery; do not treat installation as accessibility certification.
