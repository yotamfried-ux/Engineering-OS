# Scrapling

**Canonical upstream:** `D4Vinci/Scrapling`

Adaptive Python web-scraping/crawling framework with HTTP/browser fetchers, persistent sessions, structured extraction and an optional MCP server.

AI/MCP install path is documented upstream via `pip install "scrapling[ai]"`, with browser dependencies installed separately. Current releases include MCP session tools and authenticated HTTP transport behavior.

Use for authorized extraction/crawling when ordinary HTTP retrieval or browser automation is insufficient. Respect robots/terms, rate limits, authentication boundaries and applicable law; anti-bot features are not authorization to bypass access controls. Qualify against an owned/test site and verify extraction, session isolation, auth configuration and failure behavior.
