# 21st.dev MCP — conditional connection

Official source: https://docs.21st.dev/mcp
Provider endpoint: https://21st.dev/api/mcp
Reel: https://www.instagram.com/reel/DgJC0A4SF7B/

The service is an online component source and remote MCP, **not** an open-source code package that can be cloned and run offline. Connecting it to Claude Code generally requires an API key / provider login. Do not put keys in the Git repository, CLI flags captured in logs, or public workflow files. Register the remotely authenticated MCP with the user's explicit consent and check a live search result before marking it ready. Until credentials and handshake are verified, central registry state is CONDITIONAL / NOT INSTALLED.
