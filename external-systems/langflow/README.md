# Langflow

**Canonical upstream:** `langflow-ai/langflow`

Visual platform for composing AI agents/RAG workflows and exposing workflows through APIs/MCP-capable surfaces.

Use for rapid visual prototyping and integration of agent/RAG flows when a graph-based builder is useful. For production adoption verify exported/runtime behavior, secrets handling, model/vector-store dependencies, API/MCP contract and repeatable deployment rather than relying only on the visual playground.
