# Ollama

**Canonical upstream:** `ollama/ollama`

Local runtime/API for running supported open models on developer machines and servers.

Use when privacy, offline/local inference, model experimentation or avoiding per-call hosted API use is important and the available hardware can support the selected model. Qualification must record model/version, hardware, context size, latency, memory use and task-quality results. Local execution is not automatically free of infrastructure cost or usage constraints.
