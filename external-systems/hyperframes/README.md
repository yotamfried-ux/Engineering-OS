# hyperframes

Category: HTML video rendering.

Source: https://github.com/heygen-com/hyperframes — README verified against Instagram carousel DgNd6ydkU1I, 2026-11-27.

Download: `git clone https://github.com/heygen-com/hyperframes.git`

On-demand setup: npx skills add heygen-com/hyperframes; select Core Skills. Node 22+ and FFmpeg. In a new project: npx hyperframes init my-video; preview and render inside it.

Policy: inspect license, scripts and dependencies; pin reviewed revisions before use. Use authorized media, isolated workspace and non-destructive outputs. Runtime not qualified by Engineering OS.
